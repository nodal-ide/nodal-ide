# Contribute to Nodal IDE

Nodal is independently maintained by the `nodal-ide` organization. It began as a fork of CodeEdit;
the original project's history and contributor attribution remain in this repository.

## Find the project

The canonical source repository is planned at [nodal-ide/nodal-ide](https://github.com/nodal-ide/nodal-ide).
The repository and issue tracker will be available after the Nodal repository bootstrap is complete.
Please do not open Nodal issues or pull requests against CodeEditApp's repository.

## Build locally

Open `CodeEdit.xcodeproj` in Xcode, select the `CodeEdit` scheme, and allow Swift Package Manager to
resolve the project dependencies. The app is a native macOS project.

## Before opening a pull request

- Keep each pull request focused on one related change.
- Include a clear summary, related issue when available, and screenshots for user-interface changes.
- Build and run relevant checks locally; resolve new compiler and lint warnings.
- Update documentation when behavior or developer workflows change.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

The pull request template includes the complete checklist. Nodal review and support channels will be
published with the canonical repository.
